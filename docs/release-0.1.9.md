# v0.1.9 — size bare previews to the SNES screen

- Correction for v0.1.11: the bare-display samples in this release used the raw 8:7 framebuffer ratio. Use 4:3 for the complete SNES television picture; 8:7 describes the 256×224 sample grid only.
- Avoid blank space below compact SNES previews on narrow screens.
